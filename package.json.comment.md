# package.json — metadata and scripts for the project

This companion file documents the role of `package.json` and important scripts used during development and CI.

## Key scripts

- `npm install` — install dependencies
- `npm run dev` — start dev server
- `npm run build` — build for production
- `npm test` — run unit tests

Note: `package.json` is JSON and must not be modified to add comments; use this companion file for safe documentation.
